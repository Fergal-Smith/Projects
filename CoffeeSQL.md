# Coffee Shop Database

A relational database developed in a team of four for a fictional coffee shop chain using MySQL and SQL.

## My Contribution

* Created and normalised database tables to reduce data redundancy.
* Established relationships using primary and foreign keys.
* Implemented junction tables to manage many-to-many relationships.

## Technologies

MySQL, SQL, phpMyAdmin

## Key SQL Skills

* Database design and normalisation
* Primary and foreign keys
* Many-to-many relationships
* Junction tables
* JOINs
* Aggregate functions
* GROUP BY and HAVING
* Subqueries
* Data filtering and constraints
