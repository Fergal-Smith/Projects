# Projects
A portfolio containing projects I have completed during my time in DCU

## 1. Farm Product Cost Analysis Website

Technologies: Python, Django, HTML/CSS, GitLab

A Django-based website developed as part of a group project to analyse the percentage cost of farm products in supermarkets.

My contribution: GitLab repository setup, URL routing (urls.py) and database models (models.py).

## 2. Coffee Shop Database

Technologies: MySQL, SQL, phpMyAdmin

A relational database designed for a fictional coffee shop chain, managing customers, orders, menu items, staff, locations and promotional events.

My contribution: Database table design and normalisation, primary/foreign key relationships, many-to-many junction tables and SQL queries.

## 3. Django TV Information Website

Technologies: Python, Django, HTML/CSS

A Django-based website allowing users to enter and display TV information under predefined headings.

My contribution: Implemented class-based views, models and HTML templates to dynamically display database information.
